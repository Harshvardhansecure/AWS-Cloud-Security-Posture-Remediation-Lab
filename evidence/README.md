# Evidence

This folder contains sanitized visual evidence from the AWS CSPM assessment.

## Baseline Evidence

`baseline-summary.png` will show the completed initial Prowler scan and the security findings identified before remediation.

## Post-Remediation Evidence

`remediation-summary.png` will show the Prowler scan completed after selected security controls were improved.

## Sanitization Requirements

Before uploading screenshots, redact or blur:

- AWS account IDs
- IAM usernames and email addresses
- Public IP addresses
- Resource IDs and ARNs
- Browser tabs containing personal information
- Access keys, secret keys, tokens, or passwords

The original Prowler report is retained locally and is not published in this repository.
